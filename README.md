# Health Science Explained – svensk blogg om hälsovetenskap

Statisk sajt byggd med [Eleventy](https://www.11ty.dev/). Publiceras automatiskt till GitHub Pages vid varje ändring på `main`.

- **Redigera innehåll:** gå till `/admin` på sajten.
- **Artiklar:** `src/blogg/*.md`
- **Inställningar (namn, länkar):** `src/_data/site.json`
- **Design:** `src/assets/css/style.css`
- **Köra lokalt:** `npm install` och sedan `npm start` → http://localhost:8080
